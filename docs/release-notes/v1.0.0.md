**eArcNG 1.0.0** — the real eARC soundbar volume on LG webOS, in the system indicator or in an overlay. The first
release. *Русский текст — ниже.*

### What it does
- **System indicator** (`ui native`, webOS ≤ 10.x with QML): the LG indicator shows the soundbar's real number and
  bar instead of "+/−", right on key press and with native timings.
- **Overlay** (`ui overlay`, any firmware where the overlay app runs): a badge next to the native column.
- **Own app eArcNG** with an icon in the app list: `install` builds it on the TV and installs it with the system
  installer.
- **Choice on the TV**: System / Overlay buttons on the settings screen; the second press confirms (the TV
  interface restarts, open apps close, the screen may go black for ~15 s), then the settings screen opens again by
  itself and shows the result.
- **`report`**: one command for a GitHub issue (TV model, firmware, check, status, log; without the TV address).

### Install
Needs a rooted TV (Homebrew Channel, root SSH), `python3` on the TV and SIMPLINK (HDMI-CEC).
```bash
unzip earcng-1.0.0.zip && cd earcng
./tools/earcng.sh root@<TV-IP> check
./tools/earcng.sh root@<TV-IP> install
./tools/earcng.sh root@<TV-IP> ui native
```
Then open **eArcNG** from the app list. If Nikolay1243's eARC Volume Overlay is installed, `install` turns off its
`watcher.js` (it shows the TV's key-press counter); that app is not needed and can be removed in the Homebrew Channel.

### Tested
- On a TV (owner's field test, LG OLED65M59LA, webOS 10.3.0, Sony HT-A8000, Hearth launcher): the eArcNG app
  (install, icon, `uninstall` and a fresh install), both modes, switching System ↔ Overlay with confirmation and
  cancel and the settings screen reopening with the result, all settings screen buttons, the overlay on volume
  keys, `report`.
- Not checked yet: other TVs, soundbars and webOS 11.
- Automated tests without a TV (Python, Node, BusyBox, ssh stub, Bash 3.2, shellcheck) pass in CI.

## Русский

**eArcNG 1.0.0** — реальная громкость eARC-саундбара на LG webOS, в системном индикаторе или в оверлее. Первый
релиз.

### Что умеет
- **Системный индикатор** (`ui native`, webOS ≤ 10.x с QML): индикатор LG показывает реальное число и полосу
  саундбара вместо «+/−», сразу по нажатию и с нативными таймингами.
- **Оверлей** (`ui overlay`, любая прошивка, где работает приложение-оверлей): кружок рядом с нативной колонкой.
- **Своё приложение eArcNG** со значком в списке приложений: `install` собирает его на ТВ и ставит системным
  установщиком.
- **Выбор на ТВ**: кнопки «Системный» / «Оверлей» на экране настроек; второе нажатие подтверждает (интерфейс ТВ
  перезапускается, открытые приложения закрываются, экран может погаснуть на ~15 с), затем экран настроек
  открывается снова сам и показывает итог.
- **`report`**: одна команда для issue на GitHub (модель и прошивка ТВ, проверка, статус, лог; без адреса ТВ).

### Установка
Нужны rooted ТВ (Homebrew Channel, root SSH), `python3` на ТВ и SIMPLINK (HDMI-CEC).
```bash
unzip earcng-1.0.0.zip && cd earcng
./tools/earcng.sh root@<IP-ТВ> check
./tools/earcng.sh root@<IP-ТВ> install
./tools/earcng.sh root@<IP-ТВ> ui native
```
Затем откройте **eArcNG** из списка приложений. Если установлен eARC Volume Overlay от Nikolay1243, `install`
выключит его `watcher.js` (он показывает счётчик нажатий ТВ); это приложение не нужно, его можно удалить в
Homebrew Channel.

### Проверено
- На ТВ (полевой тест владельца, LG OLED65M59LA, webOS 10.3.0, Sony HT-A8000, лаунчер Hearth): приложение eArcNG
  (установка, значок, `uninstall` и установка с нуля), оба режима, переключение «Системный» ↔ «Оверлей»
  с подтверждением, отменой и повторным открытием экрана настроек с итогом, все кнопки экрана настроек, оверлей по
  кнопкам громкости, `report`.
- Пока не проверено: другие ТВ, саундбары и webOS 11.
- Автотесты без ТВ (Python, Node, BusyBox, заглушка ssh, Bash 3.2, shellcheck) проходят в CI.
