**eArcNG 1.1.0** — install from Homebrew Channel, a second volume source, plain error hints on the settings
screen. *Русский текст — ниже.*

### New
- **Install from Homebrew Channel**: add the repository
  `https://raw.githubusercontent.com/emoorpheus/earcng/main/repo.json` in Homebrew Channel, install **eArcNG**,
  open it and press **Install**: the app package carries the backend. When Homebrew Channel updates the app, the
  settings screen shows **Update**.
- **Second volume source** `--arc-source auto|cec|eim`: when the CEC bus brings no `50:7A`, the bridge asks the
  TV's eARC service `luna://com.webos.service.eim/getArcVolume` (Nikolay1243's idea from v1.4.0). `check` shows
  whether it answers (`EIM getArcVolume: …`).
- **Plain hints** for Homebrew Channel errors on the settings screen (EN/RU), the TV's error text after them.
- A removed app no longer fills the bridge log: a refused overlay launch is logged once per 5 minutes.

### Fixed
- **Install** / **Update** on the settings screen under Homebrew Channel no longer runs into the screen's 15 s
  limit (on the TV: ~13 s before, ~3 s now).
- Overlay on a cold start: when the window reached the screen late, it stayed only ~0.4 s; the time now counts from
  its first frame on screen (on the TV: ~1.5 s + fade, as intended). Since 1.0.0.
- `tools/earcng.sh` on a TV without the backend: a clear message with the way to install instead of
  `sh: can't open …`.
- Settings screen: after **Update** the focus goes to **Enable** / **Disable**; before, no button had focus until
  an arrow was pressed.

### Install or update from a PC
```bash
unzip earcng-1.1.0.zip && cd earcng-1.1.0
./tools/earcng.sh root@<TV-IP> check
./tools/earcng.sh root@<TV-IP> install
```
`install` over 1.0.0 keeps `args` and the `ui` mode.

### Tested
- On one TV (LG OLED65M59LA, webOS 10.3.0, Homebrew Channel 0.7.3) + Sony HT-A8000, over SSH without a remote:
  `check` with the `EIM getArcVolume` line; `install` over 1.0.0 (keeps `args` and `ui native`); the EIM source
  (`eim`, and `auto` without the CEC device); Homebrew Channel with a test repository on the local network: the
  list, the details page, INSTALL, **Install** on the settings screen (running within ~3 s), **Update** after a
  test 1.1.1 package; a disabled bridge stays disabled after **Update** (test packages 1.1.1 and back to 1.1.0);
  switching the indicator both ways on the settings screen; removing the app in Homebrew Channel (one
  `launch rejected` line per 5 minutes); the overlay on a cold start (launches like the bridge's).
- Not yet: this repository's address in Homebrew Channel, the start after a reboot, standby, the hints for
  Homebrew Channel errors, webOS 11.
- Automated tests without a TV (Python, Node, BusyBox, ssh stub, Bash 3.2, shellcheck) pass.

## Русский

**eArcNG 1.1.0** — установка через Homebrew Channel, второй источник громкости, понятные подсказки к ошибкам на
экране настроек.

### Новое
- **Установка через Homebrew Channel**: добавьте в Homebrew Channel репозиторий
  `https://raw.githubusercontent.com/emoorpheus/earcng/main/repo.json`, установите **eArcNG**, откройте его и
  нажмите **Установить**: пакет приложения несёт бэкенд. Когда Homebrew Channel обновит приложение, экран настроек
  покажет **Обновить**.
- **Второй источник громкости** `--arc-source auto|cec|eim`: если CEC-шина не приносит `50:7A`, мост спрашивает
  eARC-сервис ТВ `luna://com.webos.service.eim/getArcVolume` (идея Nikolay1243 из v1.4.0). `check` показывает,
  отвечает ли он (`EIM getArcVolume: …`).
- **Понятные подсказки** к ошибкам Homebrew Channel на экране настроек (EN/RU), после них — текст ошибки ТВ.
- Удалённое приложение больше не засоряет лог моста: отказ запуска оверлея пишется раз в 5 минут.

### Исправлено
- **Установить** / **Обновить** на экране настроек под Homebrew Channel больше не упираются в предел экрана 15 с
  (на ТВ: было ~13 с, стало ~3 с).
- Оверлей при холодном старте: если окно попадало на экран поздно, оно было видно лишь ~0,4 с; теперь время
  считается от его первого кадра на экране (на ТВ: ~1,5 с + fade, как задумано). С 1.0.0.
- `tools/earcng.sh` на ТВ без бэкенда: понятное сообщение, как установить, вместо `sh: can't open …`.
- Экран настроек: после **Обновить** фокус переходит на **Включить** / **Отключить**; раньше ни одна кнопка не была
  в фокусе до нажатия стрелки.

### Установка или обновление с ПК
```bash
unzip earcng-1.1.0.zip && cd earcng-1.1.0
./tools/earcng.sh root@<IP-ТВ> check
./tools/earcng.sh root@<IP-ТВ> install
```
`install` поверх 1.0.0 сохраняет `args` и режим `ui`.

### Проверено
- На одном ТВ (LG OLED65M59LA, webOS 10.3.0, Homebrew Channel 0.7.3) + Sony HT-A8000, по SSH без пульта: `check`
  со строкой `EIM getArcVolume`; `install` поверх 1.0.0 (сохраняет `args` и `ui native`); источник EIM (`eim` и
  `auto` без CEC-устройства); Homebrew Channel с тестовым репозиторием в локальной сети: список, страница
  приложения, INSTALL, **Установить** на экране настроек (работает через ~3 с), **Обновить** после тестового
  пакета 1.1.1; отключённый мост остаётся отключённым после **Обновить** (тестовые пакеты 1.1.1 и обратно 1.1.0);
  переключение индикатора в обе стороны на экране настроек; удаление приложения в Homebrew Channel (одна строка
  `launch rejected` раз в 5 минут); оверлей при холодном старте (запуски как у моста).
- Ещё нет: адрес этого репозитория в Homebrew Channel, запуск после перезагрузки, standby, подсказки к ошибкам
  Homebrew Channel, webOS 11.
- Автотесты без ТВ (Python, Node, BusyBox, заглушка ssh, Bash 3.2, shellcheck) проходят.
