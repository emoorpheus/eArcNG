**eArcNG 1.1.1** — a description with pictures on the Homebrew Channel package page. Documentation only: the
bridge and the app work as in 1.1.0. *Русский текст — ниже.*

### New
- **Homebrew Channel package page**: a description in English and Russian with three pictures (the settings
  screen, the badge, the pill and the ring). Before, Homebrew Channel 0.7.3 showed an empty description.

### Install or update
- Homebrew Channel: **UPDATE** on the eArcNG page, then **Update** on the settings screen (the app brings backend
  1.1.1, the same code as 1.1.0).
- From a PC:
```bash
unzip earcng-1.1.1.zip && cd earcng-1.1.1
./tools/earcng.sh root@<TV-IP> install
```
Re-running `install` keeps `args` and the `ui` mode.

### Tested
- On one TV (LG OLED65M59LA, webOS 10.3.0, Homebrew Channel 0.7.3): this repository's address
  `https://raw.githubusercontent.com/emoorpheus/earcng/main/repo.json` in Homebrew Channel: eArcNG in the list with
  its icon, the package page with the description (EN + RU) and the three pictures, scrolled to the end.
- 1.1.0 after two restarts of the TV: the hook started the bridge 36–39 s after boot, the native indicator patch
  was active, no errors in the bridge log.
- Not yet: installing and updating from this address, standby, the hints for Homebrew Channel errors, webOS 11.
- Automated tests without a TV (Python, Node, BusyBox, ssh stub, Bash 3.2, shellcheck) pass.

## Русский

**eArcNG 1.1.1** — описание с картинками на странице пакета в Homebrew Channel. Только документация: мост и
приложение работают как в 1.1.0.

### Новое
- **Страница пакета в Homebrew Channel**: описание на английском и русском с тремя картинками (экран настроек,
  badge, капсула и кольцо). Раньше Homebrew Channel 0.7.3 показывал пустое описание.

### Установка или обновление
- Homebrew Channel: **UPDATE** на странице eArcNG, затем **Обновить** на экране настроек (приложение несёт
  бэкенд 1.1.1, тот же код, что в 1.1.0).
- С ПК:
```bash
unzip earcng-1.1.1.zip && cd earcng-1.1.1
./tools/earcng.sh root@<IP-ТВ> install
```
Повторный `install` сохраняет `args` и режим `ui`.

### Проверено
- На одном ТВ (LG OLED65M59LA, webOS 10.3.0, Homebrew Channel 0.7.3): адрес этого репозитория
  `https://raw.githubusercontent.com/emoorpheus/earcng/main/repo.json` в Homebrew Channel: eArcNG в списке со
  значком, страница пакета с описанием (EN + RU) и тремя картинками, прокрученная до конца.
- 1.1.0 после двух перезагрузок ТВ: хук запустил мост через 36–39 с после старта, патч родного индикатора был
  активен, ошибок в логе моста нет.
- Ещё нет: установка и обновление с этого адреса, standby, подсказки к ошибкам Homebrew Channel, webOS 11.
- Автотесты без ТВ (Python, Node, BusyBox, заглушка ssh, Bash 3.2, shellcheck) проходят.
