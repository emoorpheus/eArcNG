**eArcNG 1.1.2** — more checks on a TV and a picture of the system indicator. Documentation only: the bridge and
the app work as in 1.1.0. *Русский текст — ниже.*

### New
- A screenshot of the system indicator from the TV on the Homebrew Channel package page and in the README.

### Install or update
- Homebrew Channel: **UPDATE** on the eArcNG page, then **Update** on the settings screen (the app brings backend
  1.1.2, the same code as 1.1.0).
- From a PC:
```bash
unzip earcng-1.1.2.zip && cd earcng-1.1.2
./tools/earcng.sh root@<TV-IP> install
```
Re-running `install` keeps `args` and the `ui` mode.

### Tested
- On one TV (LG OLED65M59LA, webOS 10.3.0, Homebrew Channel 0.7.3, the soundbar on eARC) with the address
  `https://raw.githubusercontent.com/emoorpheus/earcng/main/repo.json`: updating 1.1.0 → 1.1.1 and a fresh install
  (INSTALL, then **Install**: the bridge started within a second; **System** switched to the system indicator).
- The trk501 hint on **Install** (with a stand-in process that has trk501's command line, not trk501 itself).
- Mute with `--arc-source eim`; standby (the power key → Active Standby, woken by Wake-on-LAN): the bridge kept
  running and the system indicator showed the right values.
- Not yet: `auto` when the bus works but the soundbar is silent, the other Homebrew Channel error hints, webOS 11.
- Automated tests without a TV (Python, Node, BusyBox, ssh stub, Bash 3.2, shellcheck) pass.

## Русский

**eArcNG 1.1.2** — новые проверки на ТВ и картинка системного индикатора. Только документация: мост и приложение
работают как в 1.1.0.

### Новое
- Снимок системного индикатора с ТВ на странице пакета в Homebrew Channel и в README.

### Установка или обновление
- Homebrew Channel: **UPDATE** на странице eArcNG, затем **Обновить** на экране настроек (приложение несёт
  бэкенд 1.1.2, тот же код, что в 1.1.0).
- С ПК:
```bash
unzip earcng-1.1.2.zip && cd earcng-1.1.2
./tools/earcng.sh root@<IP-ТВ> install
```
Повторный `install` сохраняет `args` и режим `ui`.

### Проверено
- На одном ТВ (LG OLED65M59LA, webOS 10.3.0, Homebrew Channel 0.7.3, саундбар по eARC) с адресом
  `https://raw.githubusercontent.com/emoorpheus/earcng/main/repo.json`: обновление 1.1.0 → 1.1.1 и установка
  с нуля (INSTALL, затем **Установить**: мост запустился меньше чем через секунду; **Системный** включил системный
  индикатор).
- Подсказка про trk501 при **Установить** (с процессом-заменой с командной строкой trk501, не с самим trk501).
- Mute при `--arc-source eim`; standby (кнопка питания → Active Standby, пробуждение по Wake-on-LAN): мост
  продолжал работать, системный индикатор показывал верные значения.
- Ещё нет: `auto`, когда шина работает, а саундбар молчит, остальные подсказки к ошибкам Homebrew Channel,
  webOS 11.
- Автотесты без ТВ (Python, Node, BusyBox, заглушка ssh, Bash 3.2, shellcheck) проходят.
